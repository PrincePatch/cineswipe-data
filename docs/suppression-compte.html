Supprimer votre compte CinéSwipe

La suppression est définitive et immédiate. Elle efface le compte et tout ce qui s'y rattache.

Depuis l'application

Ouvrez l'onglet Profil, puis Paramètres, section Compte et confidentialité, et choisissez Supprimer mon compte. La suppression prend effet immédiatement.

Sans l'application

Écrivez à florian@thibault.tel depuis l'adresse électronique associée à votre compte, en demandant sa suppression. Elle est effectuée dans un délai maximum de trente jours.

Supprimer une partie de vos données, sans fermer le compte

Fermer le compte n'est pas le seul moyen d'effacer quelque chose. Depuis l'application, à tout moment et sans nous écrire :

  • un commentaire ou une réponse : le bouton Supprimer, sous vos propres commentaires ;
  • une liste que vous avez créée : Supprimer la liste, depuis la liste elle-même — les films qu'elle contient partent avec ;
  • un repost : Supprimer le repost, depuis votre profil ;
  • votre biographie et votre avatar : Modifier mon profil, en vidant le champ ou en retirant l'image ;
  • un abonnement, une demande de suivi ou un blocage.

Chaque suppression est immédiate et définitive, et ne touche à rien d'autre. Pour toute demande portant sur d'autres données, écrivez à florian@thibault.tel depuis l'adresse associée à votre compte : elle est traitée dans un délai maximum de trente jours.

Ce qui est effacé

  • le compte et son adresse électronique ;
  • le profil : pseudonyme, biographie, avatar ;
  • les listes de films créées, publiées ou enregistrées ;
  • les publications et les messages de repost ;
  • les commentaires et les réponses ;
  • les « j'aime » ;
  • les abonnements, les demandes de suivi et les blocages ;
  • les conversations privées et leurs messages.

L'effacement est en cascade : rien n'est conservé sous une forme rattachable au compte supprimé.

Ce qui n'est pas concerné

Les films enregistrés, les films vus, les critères et le profil de goûts ne sont pas stockés sur un serveur : ils vivent uniquement dans le stockage local de votre appareil. Les effacer se fait en désinstallant l'application, ou en vidant les données du site depuis votre navigateur.

Durée de conservation

Aucune. Les données supprimées ne sont pas conservées après la suppression, hors sauvegardes techniques de l'hébergeur, dont la rotation n'excède pas trente jours.
